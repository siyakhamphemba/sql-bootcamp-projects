# SQL Bootcamp Projects

A complete collection of SQL scripts written during 
a structured data analyst bootcamp. Covers everything 
from fundamentals through to advanced analysis.

## Skills Demonstrated
- SQL querying and filtering
- Data cleaning and standardization
- Exploratory data analysis
- Advanced SQL functions and optimization

## Files

### Database Setup
- `parks_rec_database_setup.sql` - Creates the Parks 
and Recreation practice database used in all exercises

### SQL Learning Progression
- `sql_fundamentals.sql` - SELECT, WHERE, GROUP BY, 
ORDER BY, HAVING, LIKE, DISTINCT, aliases
- `sql_intermediate.sql` - JOINs, UNION, String 
Functions, CASE statements, Subqueries, 
Window Functions
- `sql_advanced.sql` - CTEs, Temporary Tables, 
Stored Procedures, Triggers, Events

### Real World Projects
- `data_cleaning.sql` - Full data cleaning project 
on world layoffs dataset. Covers duplicate removal,
standardization, NULL handling and column fixes
- `exploratory_data_analysis.sql` - EDA on layoffs 
dataset. Covers rolling totals, rankings, 
year-over-year trends and country analysis

## Datasets Used
- Parks and Recreation employee database
- World layoffs dataset (2020-2023)

## Topics Covered
- SELECT, WHERE, GROUP BY, HAVING, ORDER BY
- INNER JOIN, LEFT JOIN, RIGHT JOIN, SELF JOIN
- UNION and UNION ALL
- String Functions (TRIM, CONCAT, SUBSTRING)
- CASE statements
- Subqueries
- Window Functions (ROW_NUMBER, RANK, DENSE_RANK)
- CTEs (Common Table Expressions)
- Temporary Tables
- Stored Procedures
- Triggers and Events
- Data Cleaning techniques
- Exploratory Data Analysis
